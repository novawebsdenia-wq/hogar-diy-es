El taladro es la herramienta más usada en cualquier hogar. Y también una de las más confusas de comprar: ¿con cable o sin cable? ¿Percutor o no? ¿10mm o 13mm? Esta guía te da una respuesta directa según lo que realmente necesitas.

## Antes de comprar: qué vas a taladrar

La decisión más importante no es la marca — es el tipo de pared:

| Material             | Taladro necesario                              |
| -------------------- | ---------------------------------------------- |
| Madera, yeso, pladur | Cualquier taladro básico                       |
| Ladrillo cerámico    | Taladro percutor (imprescindible)              |
| Hormigón, piedra     | Taladro percutor potente o martillo perforador |
| Azulejo, cerámica    | Taladro sin percusión + broca especial         |

Si en tu casa tienes principalmente paredes de ladrillo (la mayoría de viviendas españolas), **necesitas un taladro percutor**. Sin él, el trabajo se convierte en una tortura y deterioras tanto el taladro como la pared.

## Taladro vs atornillador: ¿cuál necesito?

| Función               | Taladro | Atornillador         |
| --------------------- | ------- | -------------------- |
| Taladrar pared        | ✅      | ❌                   |
| Atornillar muebles    | ✅      | ✅                   |
| Uso doméstico general | ✅      | Solo si no hay pared |
| Precio                | Mayor   | Menor                |

**Conclusión**: Para el hogar, un taladro siempre es mejor opción que un atornillador puro, porque lo incluye todo.

## ¿Cable o batería?

|                  | Con cable          | Con batería                   |
| ---------------- | ------------------ | ----------------------------- |
| Potencia         | Mayor y constante  | Suficiente para uso doméstico |
| Comodidad        | Limitado por cable | Libertad de movimiento        |
| Mantenimiento    | Ninguno            | Baterías que perder carga     |
| Precio           | Menor              | Mayor                         |
| Recomendado para | Uso muy ocasional  | Uso regular                   |

## Preguntas frecuentes

**¿Qué significa el par de apriete (Nm)?**
Es la fuerza de giro. Para uso doméstico, 30-50 Nm es suficiente. Para hormigón o tareas intensas, busca 60 Nm o más.

**¿Qué voltaje necesito?**
Para uso doméstico, 18V es el estándar. 12V es suficiente solo para atornillar madera y materiales blandos.

**¿Son buenas las marcas blancas de bricolaje?**
Para uso muy ocasional (colgar 2-3 cuadros al año), sí. Para uso regular, el coste en averías y la frustración de un taladro mediocre supera al ahorro inicial.
